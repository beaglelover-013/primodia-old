变量更新规则:
  总则:
    - 只更新本回合被用户行动或AI剧情结果影响到的变量。
    - replace 用于已有字段改值；delta 用于纯数字增减；insert 用于新增对象；remove 用于删除归零或离场对象。
    - 数值不得小于 0；当前值不得超过上限；数量归零时 remove 对应条目。
    - 生命、精力、声望、好感、资金、库存数量基于当前变量值增减，不凭叙事重新猜总数。
    - 输出路径使用正式中文字段名。
    - 路径必须从根开始，不得省略层级。以下是极易写错的路径对照：
      错误: /当前历法/时间 → 正确: /世界/当前历法/时间
      错误: /当前地点/区域 → 正确: /世界/当前地点/区域
      错误: /资金/随身钱袋 → 正确: /酒馆/资金/随身钱袋
      错误: /精力/当前值 → 正确: /主角/精力/当前值
      错误: /烹饪等级/做菜次数 → 正确: /主角/烹饪等级/做菜次数
    - 不确定路径时，参照变量列表中的完整层级结构。

  世界:
    时代:
      - 正式时代切换或世界观重置时更新。
    地区:
      - 跨地区旅行、迁居或明确进入新地区时更新。
    当前历法:
      - 用户行动后按实际消耗推进 时间。
      - 时间推进分档：
        烹饪:
          简单菜（煎蛋、炒青菜、拌凉菜、煮面、烤串）: 5~15分钟
          普通菜（炖菜、烧肉、烤鱼、炒肉、焗菜）: 20~40分钟
          复杂菜（慢炖汤、烤大块肉、多层点心、宴会菜）: 1~3小时
        交流:
          寒暄/点单/应答: 1~3分钟
          正常聊天/打听消息: 10~20分钟
          深入交谈/讨价还价/解决纠纷: 30分钟~1小时
          陪客人喝酒/听长篇故事: 1~2小时
        库房操作:
          分装/分菜（倒酒、切分熟食）: 1~5分钟
          分装/分菜（拆解大块生肉、分装大批干货）: 5~15分钟
          整理入库/盘点: 10~30分钟
        其他:
          换地点/短途移动: 5~20分钟
          采购/简单清扫/喂牲畜: 15~40分钟
          重体力劳动（劈柴、搬运、挖土、大扫除）: 30分钟~2小时
          营业时段: 2~4小时
          睡眠/长途旅行: 跨日
      - 跨日或跨月时同步 年、月份序号、月份名、季节、日。
      - 月份对应：1冰封月、2残雪月、3解冻月、4花萌月、5绿涨月、6长日月、7炎阳月、8收获月、9金叶月、10落穗月、11霜降月、12暗夜月。
    当前地点:
      - 实际移动到新区、酒馆区域、商铺、地图节点或客房时更新。
      - 离开商铺时清空 街坊商铺.当前商铺。

  酒馆:
    名称:
      - 正式改名或产权变化时更新。
    声望:
      - 普通顺利营业或顾客满意：+1~+3。
      - 特色菜成功、解决客人问题：+3~+6。
      - 卫生问题、食物事故、冲突或严重失误：-2~-8。
    资金:
      - 随身钱袋 用于外出采购、送礼、路上消费；钱匣 用于酒馆收入、建设、维护支出。
      - 货币换算：100铜=1银，10银=1金，500金=1铂金，500铂金=1秘银。
      - 五种面额与 折算合计铜币 同步更新。
      - 余额不足就是余额不足，不赊账，不混用两处资金。
    今日营业状态:
      - 开始营业、暂停、关店、修缮或事故整顿时 replace。
    整体概况:
      - 酒馆整体状态或经营气质被正文明确改变时更新。
    区域:
      - 正文实际清理、搭建、修缮、长期使用、正式命名某个空间时，新增或更新对应区域。
      - 状态只使用：崭新、整洁、良好、忙乱、肮脏、破损、停用、升级中。
      - 清扫提升 1~2 档；使用或忙乱下降 1 档。
      - 状态原因 写当前状态的具体原因，状态变化时同步更新。
      - 新建设施写入对应区域的 设施。
    客房:
      - 入住、退房、清洁、损坏、修缮、装修或增减设施时更新。
      - 清洁状态 写当前清洁程度的直观描述。
      - 清洁原因 写来由。脏了写原因，干净了写方式。

  主角:
    种族:
      - 正式转化、变身长期固化或用户明确改设定时更新。
    当前状态:
      - 行动导致明显体力、心情或处境变化时 replace。写短状态。
    一句话穿着:
      - 换衣、衣物破损、清洁或剧情明确变化时 replace。
    生命:
      - 轻微擦伤/不适：-1~-5；普通受伤：-6~-15；严重事故或战斗：-16~-40。
      - 治疗、包扎、休息可恢复，不超过上限。
      - 上限只在长期养成、魔法、重大剧情后更新。
    精力:
      - 轻微动作：-1~-3；采购/清扫/短途移动：-4~-10。
      - 烹饪、搬运、挖土、种植、连续采购、紧张交涉：-10~-25。
      - 长时间营业、重体力劳动、长途旅行、锻炼：-20~-40。
      - 饮食、小憩、休息、睡眠可恢复；睡眠恢复到上限。
      - 锻炼或长期养成可提高上限 +1~+3。
      - 短动作优先用 delta 小幅增减。
    烹饪等级:
      - 做菜、做酱、做饮品成功后 做菜次数 +1。
      - 达到 下级所需次数 后提升 等级，同步更新 称号。

  库房:
    - 整理入库、收获、制作完成后按实际数量 insert/delta。
    - 大块食材入库时判断 每件份数 并设 当前剩余份数=每件份数；不可分割物品每件份数=1。
    - 取出到行囊：库房 delta 负数或 remove，行囊增加同名同类条目。
    - 消耗可分割物品：优先扣 当前剩余份数 → 归零 → 数量-1 → 重置 → 数量归零则 remove。
    - 成品和酒水必须带 搭配判定；无明确判定用 无冲突。
    - 日用品消耗归零时触发"用完了"叙事。
    分装:
      - 每件份数=1 的物品可拆分为多份。一桶酒→N杯，一整块熟肉→N份，一袋散装调料→N小包。
      - 只修改 每件份数 和 当前剩余份数，不改变其他字段。分装后搭配判定不变。
      - 分装份数：一桶酒10~30杯，一块烤肉4~12份，一袋调料5~20小包。
      - 分装不可逆。已分装物品可再次分装为更小份：先消耗1份，再 insert 新条目。

  行囊:
    - 结构与库房一致，同样支持 每件份数 和 当前剩余份数。
    - 商铺购买先入行囊。取出、路上购买、路上携带时加入行囊。
    - 消耗、整理入库、丢弃、交给他人时 delta/remove。可分割物品优先扣 当前剩余份数。
    - 整理入库：行囊减少 + 库房增加。取出：库房减少 + 行囊增加。
    - 路上购买、携带、使用、交给他人、掉落、被偷，只改行囊。
    分装:
      - 规则与库房分装完全一致。

  临时状态:
    - 使用物品、短期魔法、环境布置或剧情影响时 insert。
    - 状态对象只写 名称、剩余回合、描述、来源物品。
    - 新增状态持续 1~5 回合。

  人物羁绊:
    - 只记录配角。
    - 新增配角→insert 完整条目，所有字段必须填写：
      种族、身份、羁绊阶段、阶段文字、好感、心情、所在位置、一句话穿着、备注 → 根据剧情填写。
      生命: {当前值: 100, 上限: 100}、精力: {当前值: 100, 上限: 100}、膀胱: {当前值: 0, 上限: 100} → 默认值。
      个人资金: {铜币: 0, 银币: 0, 金币: 0, 铂金币: 0, 秘银币: 0, 折算合计铜币: 0} → 默认值，后续根据角色身份和剧情调整。
      收入: {职业: '', 日收入折合铜币: 0, 结算方式: '', 备注: ''} → 默认值。
    - 配角离开场景不 remove，保留条目。
    - 互动、送礼、冲突、共同劳动后更新好感、心情、阶段、位置、穿着、生命、精力、膀胱。
    - 好感：普通友好 +1~+3；合心礼物/共同劳动 +3~+8；重要事件 +8~+15。
    - 冲突：小冲突 -1~-5；严重冲突或背叛 -8~-20。
    膀胱:
      - 时间累积：每小时 +3~+5。
      - 饮品摄入：一次 +15~+25。
      - 当前值 ≥50：有尿意，小动作增多（换坐姿、偶尔夹腿），不主动中断当前活动。
      - 当前值 ≥70：主动找厕所，可能中断非紧急活动，会留意厕所位置。
      - 当前值 ≥85：急迫，优先找厕所，几乎无法专注其他事。
      - 当前值 =100：触发失禁。
      - 当前值 ≥75且发生高潮：AI判断是否触发漏尿。
      - 上厕所→归零。



  布草库存:
    - 追踪布草在四个状态间流转：干净可用→脏污待洗→晾晒中→干净可用。
    - 客房弄脏布草：干净可用-1，脏污待洗+1。干净可用归零→触发叙事。
    - 清洗：脏污待洗-1，晾晒中+1，同时在晾晒系统新增批次。
    - 晾干收起：晾晒中-1，干净可用+1，同时 remove 晾晒批次。
    - 购买：总数和干净可用同时增加。破损丢弃：总数和对应状态数量同时减少。

  晾晒:
    - 衣物弄脏→清洗→新增晾晒批次，同步更新布草库存。
    - insert 批次时必须包含以下全部字段，不得使用其他字段名：
      晾晒物品: 如"床单"、"枕套"、"毛巾"、"桌布"、"抹布"
      晾晒位置: 炉灶旁/后院通风处/室内阴处
      来源: 如"客房日常使用"、"大厅日常使用"
      弄脏原因: 必须写具体，如"客人打翻酒杯"
      晾晒开始日: 当前日期
      晾晒开始时间: 当前时间
      预计干燥日: 根据晾晒位置推算
      干燥状态: 湿透/半干/基本干了/已干可收（新增批次固定为"湿透"）
      备注: 如"大扫除后清洗"
    - 晾晒位置由AI判断：炉灶旁最快且不受雨天影响但可能沾油烟味；后院通风处晴天快阴天慢雨天不干；室内阴处最慢。
    - 干燥状态推进：晴天+1级/天，阴天+0.5级/天，炉灶旁+1级/半天。
    - 干燥状态：湿透→半干→基本干了→已干可收。
    - 已干可收→收起时 remove 批次，同步更新布草库存。
    - 雨天室外晾晒未及时收→可能倒退为湿透。

  厩舍:
    - 状态使用 FacilityState 枚举。开局建议"停用"或"破损"。
    - 载具到达→新增条目；载具离开→remove 条目，同步更新 当前载具数。
    - 饲料从库房日用品补充；不足时叙事体现。
    - 超出容量时叙事体现拥挤，不新增载具。
    - 清理厩舍→状态提升 1~2 档，耗时 20~40分钟。

  农田与酒窖:
    - 开垦新田：insert到农田时，必须严格使用以下字段（禁止编造字段）：状态设为"空畦"，作物设为""，阶段设为0，阶段上限设为0，播种日设为0，成熟日设为0，预计产出设为""，批次标签设为[]。
    - 播种：消耗种子，状态变为"已播种"，记录当前日为播种日，阶段设为1，根据作物设定阶段上限和成熟日。
    - 每日推进：每日开始时，对比当前日与播种日。已过天数 = 当前日 - 播种日。阶段 = 已过天数 + 1。
    - 状态变化：阶段≥上限的30%→发芽；≥60%→生长期；≥上限→待收获。
    - 灾害/缺水：状态变为"受损"，连续2天不处理变为"枯萎"。
    - 收获：产出写入库房，农田状态重置为"空畦"，作物清空，阶段归零。
    - 酒窖桶：投入原料状态变为"发酵中"并记录酿造开始日；每日对比当前日推进进度，到期变为"待开桶"；开桶后产出入库，状态变"空桶"。

  禽畜圈养:
    - 圈舍状态：使用 FacilityState 枚举，开局建议"停用"。长期不清理变为"肮脏"。
    - 引进禽畜：新增条目，设定类型、品种、数量、成长阶段、产出物、产出周期、饲料需求。
    - 每日消耗：每日按禽畜数量和饲料需求，自动扣减饲料储备。饲料耗尽或圈舍肮脏→健康状况下降。
    - 每日成长：成长阶段（幼崽→成长期→成年→老年）随时间自动推进。
    - 产出触发：对比当前日与上次产出日，达到产出周期时，产出物入库房，并更新上次产出日。
    - 喂食/清理圈舍：耗时15~30分钟。


  街坊商铺:
    - 进入商铺时写 当前商铺；离开时清空。
    - 购买后扣钱、减少货架数量、加入行囊。
